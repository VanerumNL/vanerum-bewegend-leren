# Vanerum bewegend leren – dealersite

Product- en demosite over de Agili-tafel en de Motion Cubes, met Vimo als gids.

- Dealer tonen: zet `#sleutel` achter de link, bijvoorbeeld `/#voorbeeld`. Zonder sleutel toont de site Vanerum als contact.
- Dealers toevoegen of wijzigen: `dealers.json`.
- Demo's: `demo/motion-cube-lab.html`, `demo/agili-lab.html`, `demo/motion-missions.html`; Agili-productpagina: `product-agili.html`.
- Statische site zonder build-stap: geschikt voor Cloudflare Pages (build command leeg, output directory `/`).
